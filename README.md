# AI Gym Trainer Bot 💪

An interactive, sarcastic AI gym trainer chatbot built with Python, Ollama, and the Qwen 3.5 (0.8B) language model. It responds to workout excuses and diet slip-ups with humorous motivation and small fitness challenges.

## Features

- Sarcastic and humorous gym trainer personality.
- Interactive command-line chat.
- Maintains conversation history during the session.
- Responds to workout excuses and diet-related messages.
- Provides short, motivational responses.
- Ends each response with a mini fitness challenge.
- Runs locally using Ollama.

## Technologies Used

- Python
- Ollama
- Qwen 3.5 (0.8B)
- Ollama Python client

## Prerequisites

- Python installed on your computer.
- Ollama installed and running.
- The `qwen3.5:0.8b` model downloaded locally.

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/ai-gym-trainer-bot.git
cd ai-gym-trainer-bot
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Download the AI model

Install Ollama from https://ollama.com/download, then run:

```bash
ollama pull qwen3.5:0.8b
```

Make sure Ollama is running before starting the chatbot.

### 4. Run the chatbot

```bash
python gym_trainer_bot.py
```

### 5. Start chatting

Enter a message about your workout, diet, or an excuse for skipping the gym.

Type `exit` to end the conversation.

## Example Interaction

```text
Welcome to Ollama sarcastic Gym Trainer!
Type 'exit' to stop chatting.

You: I skipped the gym today.

AI: Oh, impressive! Your gym shoes must be enjoying
their permanent vacation. Do 20 squats now and earn
your comeback!
```

*Example output only; actual responses are generated by the model.*

## Limitations

- Ollama must be installed and running locally.
- The selected model must be downloaded.
- Conversation history is lost when the program exits.
- Responses depend on the model and available system resources.
